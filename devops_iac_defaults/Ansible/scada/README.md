# SCADA & PLC

Remote Ansible playbooks for PLC/SCADA protocols supported by Hayabusa Fleet and Workstations.

- `playbooks/`: vendor playbooks (Modbus, Siemens, Rockwell, Beckhoff, Mitsubishi, Omron, OPC UA, FUXA)
- Lab target example: `ubuntu-pnetnode` at `192.168.2.137` (user `pnet`)
- Use `playbooks/inventory-lab-pnetnode.yml` for the ZTP lab emulator node.
