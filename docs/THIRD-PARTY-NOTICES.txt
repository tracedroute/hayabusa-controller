D. LINUX APPLIANCE — IaC RUNNERS + SYSTEM PACKAGES + OPTIONAL COMPONENTS
========================================================================

Security model: Hayabusa Core runs Ansible/OpenTofu/SECops after LAN Approve.
The controller holds the vault and applies secret *names* only via lan.relay
(SSH/TCP). Ansible-core and OpenTofu are not installed on the controller.

1) Debian/Ubuntu packages in the Linux controller image (Bookworm slim base)
   These are separate system utilities. Typical licenses (see each package’s
   `/usr/share/doc/<pkg>/copyright` in the image). Versions below are from a
   reference build and may move with security upgrades:

   Package            Typical license family     Role
   -----------------  -------------------------  ---------------------------
   dnsmasq            GPL-2.0                      ZTP / DHCP-ish services
   iptables           GPL-2.0                      firewall / mesh helpers
   iproute2           GPL-2.0                      networking
   openssh-client     BSD / OpenSSH                SSH for LAN IaC
   rsync              GPL-3.0+                     sync / Image Nest
   squashfs-tools     GPL-2.0+                     Image Nest
   qemu-utils         GPL-2.0 / mixed              Image Nest disk helpers
   wimtools           GPL-3.0+                     Image Nest WIM
   xorriso            GPL-3.0+                     Image Nest ISO
   p7zip-full         LGPL / unRAR restriction*    archives (*unRAR has extra
                                                   terms; see package copyright)
   rpm                GPL-2.0+                     package inspection
   curl               MIT / curl                   HTTP fetch
   ca-certificates    MPL-2.0 / mixed              trust store
   openssl            Apache-2.0                   TLS utilities

   GPL Corresponding Source for Debian packages: enable `deb-src` for the
   Bookworm suite and run `apt-get source <package>=<version>` matching
   `dpkg -l`, or request a source bundle for your image tag from
   support@tracedroute.net.

4) Apache Guacamole (optional remote console on Linux controller stacks)
   License: Apache License 2.0
   Projects: https://guacamole.apache.org/
   Typical compose pins: guacamole/guacamole:1.5.5 , guacamole/guacd:1.5.5
   Distribution: typically via official Docker images. Preserve their
   LICENSE/NOTICE when redistributing images.
   The Windows Store SKU does not ship full Guacamole (placeholder only;
   optional compose under sidecar/ is for Linux-style lab setups).

5) PostgreSQL (when used as Guacamole / support database containers)
   License: PostgreSQL License (permissive)
   Project: https://www.postgresql.org/
   Typical compose pin: postgres:16-alpine

6) Other optional stack containers (Prometheus, Grafana, nginx, etc.) remain
   under their upstream licenses when deployed with full compose stacks.
   Grafana is AGPL-3.0 — review before redistribution / multi-tenant hosting.

7) Optional host RF / robotics tools (not bundled by default; used when present
   for controller-edge SDR / ADS-B / MAVLink under Hayabusa Core orchestration)
   Package / library     Typical license family     Role
   --------------------  -------------------------  ---------------------------
   rtl-sdr / rtl_fm      GPL lineage / package      NOAA weather / scanner RX
   dump1090(-fa)         GPL lineage                Local ADS-B aircraft JSON
   PyMAVLink             LGPLv3 + MIT-exception     MAVLink vehicle telemetry
                                                   (generated code exception)
   ffmpeg                GPL-2+ (distro builds)     SDR audio encode / stream

   Hayabusa Controller treats these as separate host processes or Python
   packages when installed by the operator. Provide matching package notices
   and GPL corresponding source where you redistribute the tools themselves.
   Core’s THIRD_PARTY_NOTICES.md has the fuller robotics/SDR matrix.

8) Python base image: python:3.12-slim-bookworm (PSF License for Python;
   Debian packages in the slim image retain their upstream copyrights).

9) uvicorn[standard] may pull extras such as httptools, uvloop (Linux),
   watchfiles, and PyYAML under their upstream MIT/BSD/Apache licenses.
